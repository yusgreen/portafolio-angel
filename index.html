NovaSalud

Proyecto personal · ~1 semana · junto con ML Platform

React · Vite · Node.js · Express · Prisma · SQLite

Problema

  • Saber cuánto stock hay sin contar a mano.
  • No perder productos por vencimiento.
  • Evitar totales mal calculados o acciones sin permiso.

Solución

  • Control de stock automático en cada venta.
  • Seguimiento de caducidades, proveedores y reportes.
  • El backend valida permisos y recalcula totales.

Competencias

  • Diseño de base de datos
  • API REST con Express
  • Reglas de negocio en el servidor
  • Permisos por rol
  • React con componentes reutilizables
  • Interfaz responsive

ML Platform

Proyecto personal · ~1 semana · junto con NovaSalud

Next.js · TypeScript · FastAPI · scikit-learn · pandas · matplotlib · Groq API · Ollama · SQLite

Problema

  • Datasets, entrenamientos y experimentos dispersos en archivos.
  • Comparar resultados de distintos modelos.
  • Seguir funcionando si el servicio de IA externo falla.

Solución

  • Interfaz para subir CSV, configurar entrenamientos y ver métricas.
  • Descarga de modelos con versionado automático.
  • Texto generado con Groq y respaldo local con Ollama.

Competencias

  • Next.js con FastAPI
  • scikit-learn y pandas
  • Seguimiento de experimentos
  • Versionado de modelos
  • Integración de LLM
  • Diseño con respaldo ante fallos
